0.2.0 恢复了直线和箭头，支持移动已有标注，长截图改为在编辑器里完成并可以继续编辑，贴图右键改为菜单，同时新增 X11 会话支持。

**编辑（#16、#18）**

- 形状菜单新增直线和箭头，支持颜色、线宽、撤销/重做和导出；按住 `Shift` 吸附到 45° 的整数倍。
- 不选工具时按住已有的矩形、圆形、方形、直线、箭头、文字、序号或画笔笔迹即可拖动平移，空白处拖动仍然移动选区。移动进入撤销/重做栈。

**长截图（#15、#18）**

- 点击工具栏的长截图按钮开始，按钮变为停止。编辑器和工具栏保持在原处，选区外侧显示边框和进度，选区内的滚轮和键盘交给下方窗口；再次点击按钮停止。
- 拼接结果放在原选区的位置和大小里，滚轮上下翻页，选区外仍是原截图的遮罩，和普通截图的编辑页一致。工具栏所有功能都可以继续使用：标注、保存、复制、贴图。
- 进度提示按文字宽度绘制，不再和按钮重叠；偶尔一帧对不上不再提示，连续两帧对不上才提示“滚动过快”。

**贴图（#15、#18）**

- 右键不再直接关闭贴图，而是打开菜单：复制图片、另存为…（`zenity` 或 `kdialog` 保存对话框）、关闭贴图。关闭只移除悬浮窗口，不删除图片。`Esc` 先收起菜单。

**X11（#10）**

- X11 会话自动切换后端：RandR 显示器、MIT-SHM 截图、覆盖整个显示器的编辑窗口、长截图、贴图和右键菜单，以及由独立进程持有 CLIPBOARD 的图片复制（大图用 INCR 分块，不需要 `xclip`）。
- 限制：没有窗口级智能选区（只用 CV）；文字工具不支持 XIM 输入法。

**内部**

- 编辑逻辑抽成与显示后端无关的 `editor_core`，Wayland、长图画布和 X11 共用；新增整帧软件合成 `soft_render`。

**测试**

在 niri 26.04（2560×1440、1.25 倍缩放）上实测：直线/箭头与移动撤销、贴图菜单的复制/另存为/关闭、Chrome 长页面的长截图（1585×5420，色块序号 0→97 连续、吸顶标题只出现一次、长图翻页后画的矩形落在第一屏以下的正确位置），以及原有的选区、工具、剪贴板、贴图、后台模式回归。X11 在 rootful Xwayland 中实测：编辑、长截图（880×3200 连续）、长图内标注、剪贴板（含 20 MB 的 INCR 传输）和后台模式。KDE 和 Hyprland 本版未重新实测。

下载 `babry-amd64-linux-v0.2.0` 后赋予执行权限即可运行，`SHA256SUMS` 提供校验和。Wayland 下复制图片需要 `wl-clipboard`；KDE 需要 Plasma 6.8+；贴图“另存为”需要 `zenity` 或 `kdialog`。
